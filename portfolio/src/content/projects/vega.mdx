The custom 20-inch Maksutov at Vega-Bray had been dark for ~15 years, its original control electronics gone and no documentation.
We reverse engineered the hardware, and built an ESP32-based LX200-compatible controller.
On top of that, a Go-based API serves a React frontend providing a celestial map and user interface for the telescope.
We leverage a 3D model and ROS-inspired URDF model and kinematics to build motion plans that avoid self-collisions,
a real concern with these German equatorial mount telescopes.

<ArchDiagram name="observatory" />

I additionally built a simulated telescope so that the whole system could be tested end-to-end, including firmware, before deploying to real hardware.
This drives the demo here.
